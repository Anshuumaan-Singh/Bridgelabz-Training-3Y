# JavaScript Assignment 4

The assignment contains nine separate core JavaScript solutions. `index.html` brings the interactive form and DOM exercises together; `styles.css` provides form feedback and page styling.

## Run the interactive assignment

Open `index.html` in a browser. The student and login forms show red borders and field-specific errors for invalid input, and green borders for valid fields. The library, custom form builder, ticket booking, profile editor, and shopping cart can be used directly on the page. Open the browser developer console to see the product and employee class examples.

Each question's JavaScript remains in its own numbered `.js` file. To run a script's non-DOM demonstration with Node.js, use `node NN-name.js`.
