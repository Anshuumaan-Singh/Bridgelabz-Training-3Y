# JavaScript Assignment 8

Nine runnable examples covering `reduce`, `map`, classes, prototypes, inheritance, polymorphism, validation, and error handling.

Open `index.html` in a browser to view the sample results. Select **Run all examples** or run an individual question. Each exercise also has a standalone JavaScript file in this directory.

## Exercises

1. Student result processing with a `Student` class and `reduce()`.
2. Online food ordering with `map()`, `reduce()`, and invalid item handling.
3. Product discounts with a constructor function and prototype method.
4. Employee inheritance and runtime polymorphism.
5. Ride sharing with fare validation and error handling.
6. E-commerce inventory filters, sorting, totals, and category grouping.
7. Bank account private fields, deposits, withdrawals, and errors.
8. Movie ticket inheritance and a prototype-chain method.
9. Fitness analytics with filtering, averaging, summaries, and empty-data validation.

No packages or build tools are required.
