# JavaScript Assignment 6

Ten separate, commented core JavaScript exercises on Promises, the event loop, async/await, retries, and asynchronous pipelines.

## Run with Node.js

```sh
node 01-async-coffee-maker.js
```

Use another numbered filename to run a different exercise. The Fake Store example fetches the live API by default; use `node 06-product-card-fetcher.js --offline-test` to exercise its product output with sample data without a network connection.
