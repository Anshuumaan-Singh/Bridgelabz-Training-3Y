# JavaScript Assignment 3

Ten standalone programs demonstrating conversions, validation, errors, strict mode, hoisting, closures, loops, and JSON parsing. Each question has a separate commented `.js` file and writes its output with `console.log()`. Debugging exercises include `debugger` statements and comments naming useful Watch expressions.

## Run with Node.js

```sh
node 01-dynamic-data-parser.js
```

Use the same command with another `NN-...js` filename for other questions. For the pyramid exercise, an optional positive row count can be passed as an argument, for example `node 06-pyramid-pattern-generator.js 7`; if omitted, it uses 5.
