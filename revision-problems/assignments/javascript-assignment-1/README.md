# JavaScript Assignment 1

Ten standalone programs covering core JavaScript variables, data types, operators, conditions, arrays, loops, random values, and console output. Each question is in its own commented `.js` file and uses editable sample inputs.

## Run with Node.js

From this folder, run a file by name, for example:

```sh
node 01-personalized-login-greeting.js
```

Run any other question by replacing the filename with its matching `NN-...js` file. You can also paste a file into a browser developer console. No frameworks or libraries are used.
