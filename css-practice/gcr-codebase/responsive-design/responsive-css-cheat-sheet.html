Responsive CSS cheat sheet

Four useful ideas for interfaces that adapt to the screen.

Filters

Change the appearance of an image or element with CSS effects.

filter: grayscale(1);

Media queries

Apply styles only when a screen matches a size or feature.

@media (max-width: 700px) { ... }

Responsive design

Let content rearrange naturally for phones, tablets, and desktops.

display: grid;

Typography

Scale text smoothly while keeping a readable minimum and maximum.

font-size: clamp(1rem, 2vw, 1.5rem);
