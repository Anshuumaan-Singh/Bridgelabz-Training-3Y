Three ideas to remember

Responsive design principles

Build layouts that adapt to the people and screens using them.

01

Fluid Layouts

Use flexible units and grids so content can grow or shrink with its container.

width: min(100%, 70rem);
02

Flexible Media

Let images stay within their container while keeping their natural proportions.

img { max-width: 100%; }
03

Breakpoints

Adjust the layout when the available space calls for a different arrangement.

@media (max-width: 600px) { ... }
