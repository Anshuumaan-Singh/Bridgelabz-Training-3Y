Learning in practice

Small steps make strong foundations.

A useful skill grows each time we make, try, and improve something. Start with a clear idea, then give yourself room to learn as you go.

Good work takes shape through attention, feedback, and a willingness to return to the details. A steady pace gives ideas time to become clear and useful.

01

Notice

Look closely at the problem before choosing a solution.

02

Make

Build a small version that lets you test the idea.

03

Improve

Use what you learn to make the next version better.
